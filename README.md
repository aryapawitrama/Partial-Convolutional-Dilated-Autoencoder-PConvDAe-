# Partial-Convolutional-Dilated-Autoencoder-PConvDAe-
This repository contains code implementation for the spatial reconstruction of Precipitable Water Vapor (PWV) using a Partial Convolutional Dilated Autoencoder (PConvDAe). The model leverages short-term temporal evolution and spatial structure of Himawari-8 Advanced Himawari Imager (AHI) water-vapor bands to reconstruct full-grid GNSS networks.

All Himawari-8 satellite data from the Japan Aerospace Exploration Agency used in this study (Bands 08, 09, and 10) are available in the JAXA P-Tree FTP system. Access registration details are available at https://www.eorc.jaxa.jp/ptree/userguide.html. Radiosonde pressure-level specific humidity and temperature observations used to calculate radiosonde PWV are from the Japan Meteorological Agency and available at https://www.data.jma.go.jp/stats/etrn/upper/. GNSS Zenith Tropospheric Delay (ZTD) and Zenith Hydrostatic Delay (ZHD) data used to calculate GNSS-PWV are from the Geospatial Information Authority of Japan (GSI) and available at the GSI FTP system. Access registration details are available at https://www.gsi.go.jp/denshi/denshi_data.html.The Japan Meteorological Agency's Grid Point Value Meso-scale Model (GPV-MSM) surface temperature and surface pressure data is available at https://database.rish.kyoto-u.ac.jp/arch/jmadata/ (repository of Kyoto University). The Japan Meteorological Agency's JRA-3Q dataset is available at https://gdex.ucar.edu/datasets/d640000/. The datasets generated during this study are available from the corresponding author upon reasonable request.

This code utilized a pre-processed data which is loaded as NumPy array (npy) file and comma delimeted file (.csv).
